# Envision-team

Shared Envision skills and SOPs for teammates.

- [envision-contact-sourcing](.claude/skills/envision-contact-sourcing/SKILL.md): find and verify brand marketing contacts and emails.

## How to use

**One-time setup**
1. Accept the GitHub invite (from the email).
2. Open the Claude desktop app, go to the Code tab, and pick your **Documents** folder.
3. Type: `Clone https://github.com/roxellemc-gitqueen/Envision-team`
4. Start a new session and pick **Documents → Envision-team** as the folder.

**Every time**

Open the **Envision-team** folder in the Code tab and type:

```
/envision-contact-sourcing Brand A, Brand B, Brand C
```
